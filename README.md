## Featured case study: Aurelia v3.13.0

Aurelia is a local-first digital illustration and animation studio written in Rust with a narrow
Win32 FFI boundary. The v3.13.0 release demonstrates:

- Secure binary parsing with aggregate resource and memory budgets.
- Rust ownership and explicit Windows FFI lifecycle management.
- Durable file persistence and crash-recovery behavior.
- Cryptographically verified distribution with signed SHA-256 manifests.
- Automated local quality gates and a reproducibility assessment.

[Read the engineering case study](https://github.com/LeTrollologist/Aurelia/blob/main/PORTFOLIO.md) · [v3.13.0 release](https://github.com/LeTrollologist/Aurelia/releases/tag/v3.13.0)
